TechHelp | Individual Project Site Plan

Site Name

TechHelp

This name represents a company focused on providing beginner-friendly software support, website creation services, and professional tech solutions.

Optional domain: techhelp.com

Site Purpose

The website will provide information about software services, including website building, troubleshooting, and paid professional support.

Scenarios

  • What software services does TechHelp offer and how much do they cost?
  • How can I request professional support or get a quote for a website project?

Color Scheme

Primary color (headings, buttons, accents): #004aad

Secondary color (background, sections, accents): #f0f0f0

Typography

  • Quicksand Bold: Headings
  • Quicksand Regular: Body text

Wireframe

Mobile View: Logo → Hamburger menu → Hero image → Services/pricing → Contact button → Footer

Desktop/Tablet View: Logo + nav links → Hero → Services grid → Call-to-action → Footer

Testing Plan

  • HTML Validation: W3C Markup Validator
  • Accessibility: WAVE Web Accessibility Evaluation Tool
  • SEO & Performance: Google PageSpeed Insights / Lighthouse
  • Color Contrast: WebAIM Contrast Checker
